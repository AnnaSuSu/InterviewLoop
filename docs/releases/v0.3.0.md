# TechSpar v0.3.0

这是 TechSpar 全量迁移到 TypeScript + Bun + Hono 后的首个 Electron 桌面版本。

## 下载

- macOS Apple Silicon：`TechSpar-0.3.0-mac-arm64.dmg`（推荐）或 ZIP。
- Windows x64：`TechSpar-0.3.0-win-x64.exe`（NSIS 安装包）。

桌面包已经包含 Electron、Web 前端、编译后的 Bun/Hono sidecar 和 ONNX Runtime，最终用户不需要安装 Bun、Node.js 或 Python。

## 主要内容

- Python/FastAPI 旧版冻结在 `legacy/python-backend`；`main` 只保留 TypeScript 主线。
- Hono API 保持迁移前 62 个路径、71 个 HTTP 操作的兼容清单。
- Renderer 启用 sandbox 与 context isolation，关闭 Node integration；sidecar 只监听动态 `127.0.0.1` 端口。
- 数据、模型缓存和每次安装随机生成的运行密钥写入系统应用数据目录。
- 本地 Embedding 使用 Transformers.js + ONNX，不再依赖 Python、PyTorch 或 pip。

## 安装提示

当前包没有 Apple Developer ID 或 Windows Authenticode 商业签名，因此 macOS Gatekeeper 或 Windows SmartScreen 可能显示安全提示。macOS 包已完成打包态启动冒烟；Windows 包已完成安装器、x64 Bun sidecar 和 ONNX 原生资源结构检查，真实 Windows 安装验收仍需补做。

首次使用前建议备份旧数据。不要让 `legacy/python-backend` 与 v0.3.0 同时写入同一份 SQLite 数据库或用户目录。
