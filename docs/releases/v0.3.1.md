# TechSpar v0.3.1

v0.3.1 是 Python → TypeScript/Bun/Hono/Electron 迁移的完整性收尾版本。它在 v0.3.0 桌面版基础上补齐迁移审计发现的业务语义、数据兼容、安全和发布工程问题；`main` 继续作为唯一开发主线，Python 版本只保存在 `legacy/python-backend`。

## 下载

- macOS Apple Silicon：`TechSpar-0.3.1-mac-arm64.dmg`（推荐）或 `TechSpar-0.3.1-mac-arm64.zip`。
- Windows x64：`TechSpar-0.3.1-win-x64.exe`（NSIS 安装包）。
- 完整性校验：同一 Release 中的 `SHA256SUMS.txt`。

桌面包包含 Electron、Web 前端、编译后的 Bun/Hono sidecar 和 ONNX Runtime。最终用户不需要安装 Bun、Node.js、Python、PyTorch 或 pip。

## 本次完成

- 恢复旧 FastAPI 对 `null`、验证错误、OpenAPI 安全声明和 Copilot 双内容类型的兼容语义。
- 修复个人 Agent 新会话、完整消息响应、稀疏面试答案错配、简历复盘分数和文档索引状态。
- 恢复本地/远程 Embedding 配置迁移、简历与知识库语义检索、长期画像的向量记忆、时间衰减、SM-2 与 consolidation。
- 兼容 Python `tarfile` 生成的 PAX/GNU/Unicode 归档，同时保留路径、链接、重复项、条目数和解压大小防护。
- 增加管理员全站离线恢复的 dry-run、显式确认、完整性检查、时间戳备份与失败回滚。
- 为 SQLite 后台任务增加原子 claim、租约心跳、过期接管和 owner fencing。
- 桌面端改为每次安装生成随机本机凭据；Renderer 仅能通过来源校验后的最小 IPC 建立会话；Hono 不再全局开放跨域。
- 把前端锁定版 Lint、桌面 sidecar/应用目录打包，以及 macOS/Windows Release 构建纳入自动检查。

完整审计、修复项与验证证据见 [TypeScript 迁移完整性收尾清单](https://github.com/AnnaSuSu/TechSpar/blob/v0.3.1/docs/typescript-migration-closeout.md)。

## 升级

### 从 v0.3.0 桌面版

退出正在运行的 TechSpar 后直接安装 v0.3.1。首次启动会自动保留既有应用数据，并把旧桌面版的固定 bootstrap 密码一次性轮换为本机随机凭据；用户不需要手工填写该密码。

### 从 Python 旧版

1. 停止旧 Python 服务并完整备份 SQLite、用户文件和模型目录。
2. 普通用户优先从旧版导出个人归档，再在新版导入；v0.3.1 已兼容 Python 归档中的 PAX 扩展头。
3. 管理员恢复全站包时，先运行 `bun run restore:system -- --archive=... --data-dir=...` 做 dry-run；确认所有 TechSpar 进程已停止后再增加 `--confirm`。
4. 不要让 `legacy/python-backend` 与 v0.3.1 同时写同一份 SQLite 或用户目录，也不要在两个版本之间共用数据软链接。

## 安装与验收边界

当前公开包没有 Apple Developer ID 或 Windows Authenticode 商业签名，因此 Gatekeeper 或 SmartScreen 可能显示安全提示。自动发布流程会分别在 macOS 和 Windows runner 上构建目标平台安装包；真实安装与启动仍建议在对应目标平台验收。
